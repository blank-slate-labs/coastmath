# Contributing

**Issues are welcome.** Bug reports, wrong figures, and questions about how
the planner models something all go to the issue tracker. For a wrong figure,
name the file under `backend/coastmath/data/` and the primary source that
disagrees with it.

**Pull requests are not accepted at this time.** This repository is published
from a private repository, and pull requests opened here are closed without
review. Open an issue instead; a fix made upstream appears here with the next
release.

**Security problems** go to the address in [SECURITY.md](SECURITY.md), never
to a public issue.
